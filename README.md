# Calculators

A simple and interactive **Calculator web application** built using **HTML, CSS, and JavaScript**.

## Overview

This project demonstrates how to build a calculator interface and implement calculator functionality using core frontend technologies.

The project focuses on creating a clean user interface while using JavaScript to handle user interactions and calculations.

## Features

* Calculator user interface
* Interactive buttons
* Arithmetic calculations
* JavaScript-based functionality
* CSS-based styling
* Simple and lightweight implementation

## Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling and layout
* **JavaScript** – Calculator functionality and user interactions

## Project Structure

```text
Calculators/
│
├── index.html
├── index.js
├── style.css
└── README.md
```

## How It Works

The application follows a simple frontend flow:

```text
User Interaction
       ↓
Calculator Buttons
       ↓
JavaScript Logic
       ↓
Calculation
       ↓
Displayed Result
```

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/poojakuver535/Calculators.git
```

### Navigate to the Project

```bash
cd Calculators
```

### Run the Application

Open `index.html` in a modern web browser.

For development, you can use the **Live Server** extension in Visual Studio Code.
